## 1. Rubyのバージョンについて

### 現在のバージョン状況

| バージョン | ステータス | サポート終了予定 |
|-----------|----------|----------------|
| Ruby 3.3.x | 最新安定版 | 2027年3月 |
| Ruby 3.2.x | 安定版 | 2026年3月 |
| Ruby 3.1.x | セキュリティ修正のみ | 2025年3月 |
| Ruby 3.0.x | EOL | サポート終了 |
| Ruby 2.7.x | EOL | サポート終了 |

### バージョン選択の指針

```
新規プロジェクト → 最新安定版（3.3.x）を推奨
既存プロジェクト → .ruby-version ファイルに従う
レガシー対応   → 2.7以上を推奨（それ以前は非推奨）
```

### バージョン確認方法

```bash
# インストールされているRubyのバージョン
ruby -v
# => ruby 3.3.0 (2023-12-25 revision 5124f9ac75) [x64-mingw-ucrt]

# 詳細情報
ruby --version

# RubyGemsのバージョン
gem -v

# Bundlerのバージョン
bundle -v
```

## 2. Windowsでのインストール

### RubyInstaller（推奨）

RubyInstallerはWindows向けの公式インストーラーです。

#### ダウンロードとインストール

1. [RubyInstaller公式サイト](https://rubyinstaller.org/)にアクセス
2. **WITH DEVKIT** 版をダウンロード（ネイティブ拡張のビルドに必要）
3. インストーラーを実行

#### インストール時の選択肢

```
☑ Add Ruby executables to your PATH
☑ Associate .rb and .rbw files with this Ruby installation
☑ Use UTF-8 as default external encoding
```

#### MSYS2のセットアップ

インストール完了後、MSYS2セットアップ画面が表示されます：

```
Which components shall be installed? If unsure press ENTER

1 - MSYS2 base installation
2 - MSYS2 system update (optional)
3 - MSYS2 and MINGW development toolchain

→ 3 を入力してEnter（すべてインストール）
```

#### インストール確認

```powershell
# PowerShellまたはコマンドプロンプトで確認
ruby -v
gem -v
ridk version  # MSYS2の確認
```

### Chocolateyを使用する場合

```powershell
# Chocolateyがインストールされている場合
choco install ruby

# バージョン指定
choco install ruby --version=3.3.0
```

### WSL2を使用する場合（推奨）

Windows上でLinux環境を使用する方法です。

```powershell
# WSL2を有効化（管理者権限のPowerShell）
wsl --install

# Ubuntuがインストールされる
# 以降はLinuxの手順に従う
```

## 3. macOSでのインストール

### システムRuby（非推奨）

macOSにはRubyがプリインストールされていますが、以下の理由で使用は推奨されません：

- バージョンが古い
- システム用途のため変更すると問題が起きる可能性
- gem installに管理者権限が必要

### Homebrewでインストール

```bash
# Homebrewがない場合はインストール
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Rubyをインストール
brew install ruby

# PATHを設定（.zshrc または .bash_profile に追加）
echo 'export PATH="/opt/homebrew/opt/ruby/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

# 確認
ruby -v
which ruby  # /opt/homebrew/opt/ruby/bin/ruby であること
```

### rbenv + ruby-build（推奨）

複数バージョンを管理する場合に最適です。

```bash
# インストール
brew install rbenv ruby-build

# シェルへの統合（.zshrc または .bash_profile に追加）
echo 'eval "$(rbenv init -)"' >> ~/.zshrc
source ~/.zshrc

# インストール可能なバージョン一覧
rbenv install -l

# Rubyをインストール
rbenv install 3.3.0

# グローバルに設定
rbenv global 3.3.0

# 確認
ruby -v
rbenv versions
```

### asdf（多言語バージョン管理）

Node.js、Python なども管理する場合に便利です。

```bash
# asdfをインストール
brew install asdf

# .zshrc に追加
echo '. $(brew --prefix asdf)/libexec/asdf.sh' >> ~/.zshrc
source ~/.zshrc

# Rubyプラグインを追加
asdf plugin add ruby

# インストール
asdf install ruby 3.3.0
asdf global ruby 3.3.0
```

## 4. Linuxでのインストール

### Ubuntu/Debian

#### パッケージマネージャー（簡易）

```bash
# 最新版ではない可能性がある
sudo apt update
sudo apt install ruby-full

ruby -v
```

#### rbenv（推奨）

```bash
# 依存パッケージをインストール
sudo apt update
sudo apt install -y git curl libssl-dev libreadline-dev zlib1g-dev \
  autoconf bison build-essential libyaml-dev libreadline-dev \
  libncurses5-dev libffi-dev libgdbm-dev

# rbenvをインストール
git clone https://github.com/rbenv/rbenv.git ~/.rbenv
echo 'export PATH="$HOME/.rbenv/bin:$PATH"' >> ~/.bashrc
echo 'eval "$(rbenv init -)"' >> ~/.bashrc
source ~/.bashrc

# ruby-buildをインストール
git clone https://github.com/rbenv/ruby-build.git ~/.rbenv/plugins/ruby-build

# Rubyをインストール
rbenv install 3.3.0
rbenv global 3.3.0

ruby -v
```

### CentOS/RHEL/Fedora

```bash
# 依存パッケージ
sudo dnf install -y git gcc make bzip2 openssl-devel readline-devel \
  zlib-devel libffi-devel

# rbenvのインストールは上記と同様
```

### Docker

```dockerfile
# 公式イメージを使用
FROM ruby:3.3

WORKDIR /app
COPY . .

RUN bundle install

CMD ["ruby", "app.rb"]
```

```bash
# 対話的に実行
docker run -it ruby:3.3 irb
```

## 5. バージョン管理ツール

### rbenv

最も広く使われているRubyバージョン管理ツールです。

```bash
# よく使うコマンド
rbenv install -l          # インストール可能なバージョン一覧
rbenv install 3.3.0       # インストール
rbenv uninstall 3.3.0     # アンインストール
rbenv versions            # インストール済みバージョン
rbenv version             # 現在のバージョン
rbenv global 3.3.0        # グローバル設定
rbenv local 3.2.0         # プロジェクト単位の設定（.ruby-version作成）
rbenv shell 3.1.0         # 現在のシェルのみ
rbenv rehash              # shimの再構築
```

#### .ruby-version ファイル

プロジェクトルートに配置すると、自動的にそのバージョンが使用されます。

```
3.3.0
```

### RVM（Ruby Version Manager）

rbenvの代替ツールです。

```bash
# インストール
\curl -sSL https://get.rvm.io | bash -s stable

# 使用方法
rvm list known            # インストール可能なバージョン
rvm install 3.3.0
rvm use 3.3.0 --default
rvm list                  # インストール済み
```

### asdf

多言語対応のバージョン管理ツールです。

```bash
# Rubyプラグイン追加
asdf plugin add ruby

# コマンド
asdf list all ruby        # 利用可能なバージョン
asdf install ruby 3.3.0   # インストール
asdf global ruby 3.3.0    # グローバル設定
asdf local ruby 3.3.0     # ローカル設定（.tool-versions作成）
asdf list ruby            # インストール済み
```

#### .tool-versions ファイル

```
ruby 3.3.0
nodejs 20.10.0
python 3.12.0
```

## 6. エディタ・IDEの設定

### Visual Studio Code（推奨）

#### 必須拡張機能

| 拡張機能 | 機能 |
|---------|------|
| **Ruby LSP** | 構文ハイライト、補完、定義ジャンプ |
| **Ruby Solargraph** | IntelliSense、ドキュメント |
| **Rubocop** | リンター、フォーマッター |

#### settings.json

```json
{
  "ruby.useBundler": true,
  "ruby.useLanguageServer": true,
  "ruby.lint": {
    "rubocop": {
      "useBundler": true
    }
  },
  "[ruby]": {
    "editor.defaultFormatter": "Shopify.ruby-lsp",
    "editor.formatOnSave": true,
    "editor.tabSize": 2,
    "editor.insertSpaces": true
  },
  "files.associations": {
    "Gemfile": "ruby",
    "Rakefile": "ruby",
    "*.gemspec": "ruby"
  }
}
```

#### Solargraphの設定（プロジェクトルートに配置）

**.solargraph.yml:**
```yaml
include:
  - "**/*.rb"
exclude:
  - spec/**/*
  - test/**/*
  - vendor/**/*
require: []
domains: []
reporters:
  - rubocop
  - require_not_found
max_files: 5000
```

### RubyMine（JetBrains）

商用IDEですが、最も強力なRuby開発環境です。

- 自動補完
- リファクタリング
- デバッガ統合
- Rails完全サポート
- データベースツール

### Vim/Neovim

```vim
" .vimrc または init.vim

" vim-ruby（構文ハイライト、インデント）

" endwise（end自動補完）
```

## 7. 最初のRubyプログラム

### Hello World

**hello.rb:**
```ruby
puts "Hello, World!"
```

```bash
# 実行
ruby hello.rb
```

### 対話的実行

```bash
# -e オプションで直接実行
ruby -e 'puts "Hello, World!"'

# 複数行
ruby -e '
  name = "Ruby"
  puts "Hello, #{name}!"
'
```

### シバン（Unix系）

**hello.rb:**
```ruby
#!/usr/bin/env ruby

puts "Hello, World!"
```

```bash
chmod +x hello.rb
./hello.rb
```

### 文字エンコーディング

Ruby 2.0以降、デフォルトはUTF-8です。

```ruby
# ファイル先頭でエンコーディング指定（必要な場合のみ）
# encoding: utf-8

# または
# -*- coding: utf-8 -*-

puts "日本語も使えます"
```

## 8. 対話型シェル（IRB）

### 基本的な使い方

```bash
irb
```

```ruby
irb(main):001:0> 1 + 1
=> 2
irb(main):002:0> "Hello".upcase
=> "HELLO"
irb(main):003:0> [1, 2, 3].map { |n| n * 2 }
=> [2, 4, 6]
irb(main):004:0> exit
```

### IRBの設定

**~/.irbrc:**
```ruby
# 履歴を保存
IRB.conf[:SAVE_HISTORY] = 1000
IRB.conf[:HISTORY_FILE] = "#{ENV['HOME']}/.irb_history"

# 自動補完
require 'irb/completion'

# プロンプトをシンプルに
IRB.conf[:PROMPT_MODE] = :SIMPLE

# 便利なメソッド
def clear
  system('clear') || system('cls')
end
```

### 便利なコマンド

```ruby
# 最後の結果を参照
irb> 1 + 1
=> 2
irb> _ * 3
=> 6

# 複数行入力
irb> def hello
irb>   puts "Hello"
irb> end
=> :hello

# ヘルプ
irb> help

# ソースを表示（Ruby 3.0+）
irb> show_source Array#map
```

### Pry（IRBの高機能版）

```bash
gem install pry
pry
```

```ruby
# 構文ハイライト
# コード補完
# ソースコード表示
pry> show-source Array#map

# ドキュメント表示
pry> show-doc Array#map

# 終了
pry> exit
```

## 9. トラブルシューティング

### よくある問題と解決策

#### 「ruby: command not found」

```bash
# PATHを確認
echo $PATH

# rbenv使用時
eval "$(rbenv init -)"
rbenv rehash

# 再度確認
which ruby
```

#### Gemインストールでパーミッションエラー

```bash
# 悪い例（sudoは使わない）
sudo gem install rails  # ❌

# 良い例
# 1. rbenvやrvmを使用する
# 2. --user-installオプション
gem install rails --user-install

# GEM_HOMEを設定
export GEM_HOME="$HOME/.gem"
export PATH="$HOME/.gem/bin:$PATH"
```

#### ネイティブ拡張のビルドエラー

```bash
# macOS
xcode-select --install

# Ubuntu
sudo apt install build-essential

# Windows
# RubyInstallerのDEVKIT版を使用
ridk install
```

#### SSL証明書エラー

```bash
# 証明書を更新
gem update --system
gem install bundler

# 環境変数で指定（一時的）
export SSL_CERT_FILE=/path/to/cacert.pem
```

#### Bundlerのバージョン問題

```bash
# 特定バージョンをインストール
gem install bundler -v 2.4.0

# 使用するバージョンを指定
bundle _2.4.0_ install
```

### 環境情報の取得（問題報告時に有用）

```bash
# システム情報
ruby -e "puts RUBY_DESCRIPTION"
ruby -e "puts Gem::VERSION"
ruby -e "puts Gem.path"

# 詳細情報
gem env
bundle env
```
