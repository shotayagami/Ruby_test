## 1. Rubyらしいコード

### 明示的より暗黙的

```ruby
# 悪い例: 冗長
if array.length > 0
  # ...
end

# 良い例: 簡潔
if array.any?
  # ...
end

# 悪い例: 不要なreturn
def add(a, b)
  return a + b
end

# 良い例: 最後の式が戻り値
def add(a, b)
  a + b
end

# 悪い例: 不要なself
def full_name
  self.first_name + " " + self.last_name
end

# 良い例: self省略
def full_name
  "#{first_name} #{last_name}"
end
```

**🐍 Python:**
```python
def add(a, b):
    return a + b  # return は省略できない（最後の式は自動で返らない）


class User:
    def full_name(self):
        return f"{self.first_name} {self.last_name}"  # self は常に明示
```

### 述語メソッド

```ruby
# ?で終わるメソッドは真偽値を返す
def admin?
  role == "admin"
end

def valid?
  errors.empty?
end

def empty?
  @items.empty?
end

# 使用
if user.admin?
  show_admin_panel
end
```

> **🐍 Python:** メソッド名に `?` は使えない。慣例で `is_admin` / `has_error` のように `is_` / `has_` を付け、真偽を返す関数として定義する。

### 破壊的メソッド

```ruby
# !で終わるメソッドは元のオブジェクトを変更
array = [3, 1, 2]
sorted = array.sort    # 新しい配列を返す
array.sort!            # array自体をソート

# または例外を発生させる
user.save   # 失敗時はfalseを返す
user.save!  # 失敗時は例外を発生
```

> **🐍 Python:** `!` の慣例はない。`list.sort()` は破壊的で `None` を返し、`sorted(list)` は新しいリストを返す、のように別メソッド/関数で区別する。

## 2. 条件分岐のイディオム

### 後置if/unless

```ruby
# 1行で書ける場合
return if user.nil?
raise ArgumentError unless valid?
puts "Hello" if verbose?

# 複雑な場合は通常のif
if user.admin? && user.active?
  grant_access
end
```

> **🐍 Python:** 後置 `if` や `unless` はない。`if user is None: return` のように通常の `if` 文で書き、否定は `if not valid:` とする。

### 三項演算子

```ruby
# シンプルな条件
status = active? ? "有効" : "無効"

# 複雑な場合はifを使う
result = if complex_condition?
           complex_true_value
         else
           complex_false_value
         end
```

> **🐍 Python:** `status = "有効" if active else "無効"`（値 → 条件 → 値 の順で、条件が中央に来る）。

### 論理演算子でのデフォルト値

```ruby
# || でデフォルト値
name = params[:name] || "Guest"

# ||= で遅延初期化
@users ||= User.all

# 注意: false や nil を区別する必要がある場合
# ||= は false を上書きしてしまう
@enabled ||= true  # @enabled が false でも true になる

# nilのみチェックする場合
@enabled = default_enabled if @enabled.nil?
# または
@enabled //= default_enabled  # Ruby 2.3+（実験的）
```

**🐍 Python:**
```python
name = params.get("name") or "Guest"    # || 相当
self.users = self.users or User.all()   # ||= 相当（再代入する）
config.setdefault("key", default)       # 辞書キーの既定値（||= に近い）
```

Rubyの `||` が偽とみなすのは `nil`/`false` のみだが、Pythonの `or` は `0`・`""`・空リストなども偽扱いになる。空文字列などを残したい場合は `x if x is not None else default` を使う。

### 安全ナビゲーション演算子

```ruby
# &. でnilチェック
user&.name           # userがnilならnil
user&.address&.city  # チェーン可能

# 配列やハッシュでも
array&.first
hash&.dig(:user, :name)

# メソッド呼び出しと組み合わせ
user&.admin? || false
```

**🐍 Python:**
```python
user.name if user else None                      # user&.name 相当
user and user.address and user.address.city      # チェーン（冗長になりがち）
```

`&.` に相当する演算子はPythonにはない。辞書の深いネストなら `data.get("user", {}).get("name")` のように `.get` を連ねる。

### case/when の活用

```ruby
# 型によるマッチング
case value
when String
  process_string(value)
when Array
  process_array(value)
when Hash
  process_hash(value)
end

# 範囲でマッチング
case score
when 90..100 then "A"
when 80...90 then "B"
when 70...80 then "C"
else "F"
end

# 正規表現でマッチング
case email
when /@gmail\.com$/
  "Gmail"
when /@yahoo\.com$/
  "Yahoo"
else
  "Other"
end

# Procでマッチング
even = ->(n) { n.even? }
case number
when even
  "偶数"
else
  "奇数"
end
```

**🐍 Python:**（3.10+ の構造的パターンマッチング）
```python
match value:
    case str():
        process_string(value)
    case list():
        process_array(value)
    case dict():
        process_hash(value)

# 範囲や条件はガード節で表す
match score:
    case n if 90 <= n <= 100:
        grade = "A"
    case n if 80 <= n < 90:
        grade = "B"
    case _:
        grade = "F"
```

正規表現による分岐は `match` では書けないため、`if re.search(...)` の連鎖で表現する。

## 3. コレクション操作

### map/collect

```ruby
# 変換
numbers = [1, 2, 3, 4, 5]
squares = numbers.map { |n| n ** 2 }

# メソッド参照
names = users.map(&:name)

# 複数の値を返す
users.map { |u| [u.id, u.name] }

# ネストした配列を平坦化
arrays.flat_map { |arr| arr.map(&:upcase) }
```

**🐍 Python:**
```python
squares = [n ** 2 for n in numbers]        # map 相当（内包表記が基本）
names = [u.name for u in users]            # map(&:name) 相当
list(map(lambda n: n ** 2, numbers))       # 組み込み map() でも可
# flat_map 相当（二重内包表記）
[x.upper() for arr in arrays for x in arr]
```

### select/reject

```ruby
# フィルタリング
evens = numbers.select(&:even?)
adults = users.select { |u| u.age >= 18 }

# 除外
odds = numbers.reject(&:even?)
inactive = users.reject(&:active?)

# 組み合わせ
active_adults = users.select(&:active?).select { |u| u.age >= 18 }
```

**🐍 Python:**
```python
evens = [n for n in numbers if n % 2 == 0]     # select 相当
adults = [u for u in users if u.age >= 18]
odds = [n for n in numbers if n % 2 != 0]      # reject は条件を反転（not）で表す
list(filter(lambda u: u.is_active, users))     # filter() でも可
```

### reduce/inject

```ruby
# 合計
sum = numbers.reduce(0) { |acc, n| acc + n }
sum = numbers.reduce(:+)
sum = numbers.sum  # Ruby 2.4+

# オブジェクトの構築
hash = array.reduce({}) { |h, item| h.merge(item.id => item) }

# each_with_object（reduceの代替）
hash = array.each_with_object({}) { |item, h| h[item.id] = item }
```

**🐍 Python:**
```python
from functools import reduce

total = reduce(lambda acc, n: acc + n, numbers, 0)  # reduce(0) { } 相当
total = sum(numbers)                                 # sum 相当（こちらが慣用的）
# each_with_object 相当は辞書内包が読みやすい
d = {item.id: item for item in array}
```

### group_by/partition

```ruby
# グループ化
by_status = users.group_by(&:status)
# => { "active" => [...], "inactive" => [...] }

# 2分割
passed, failed = students.partition { |s| s.score >= 60 }
```

**🐍 Python:**
```python
from collections import defaultdict

by_status = defaultdict(list)                     # group_by 相当
for u in users:
    by_status[u.status].append(u)

passed = [s for s in students if s.score >= 60]   # partition 相当
failed = [s for s in students if s.score < 60]
```

`itertools.groupby` もあるが、事前に同じキーでソートしておかないと期待通りにグループ化されない点に注意。

### any?/all?/none?/one?

```ruby
# いずれか
users.any?(&:admin?)

# すべて
users.all?(&:active?)

# どれも〜ない
users.none?(&:banned?)

# ちょうど1つ
users.one?(&:superadmin?)
```

**🐍 Python:**
```python
any(u.is_admin for u in users)        # any? 相当
all(u.is_active for u in users)       # all? 相当
not any(u.is_banned for u in users)   # none? 相当
sum(1 for u in users if u.is_superadmin) == 1  # one? に相当する組み込みはない
```

### find/detect

```ruby
# 最初の一致
admin = users.find(&:admin?)
admin = users.detect(&:admin?)

# 見つからない場合のデフォルト
user = users.find { |u| u.id == id } || User.new
```

**🐍 Python:**
```python
admin = next((u for u in users if u.is_admin), None)  # find 相当（第2引数が既定値）
user = next((u for u in users if u.id == id), User())
```

### sort/sort_by

```ruby
# ソート
sorted = users.sort { |a, b| a.name <=> b.name }

# sort_by（より高速で読みやすい）
sorted = users.sort_by(&:name)
sorted = users.sort_by { |u| [u.last_name, u.first_name] }

# 降順
sorted = users.sort_by(&:created_at).reverse
sorted = users.sort_by { |u| -u.created_at.to_i }
```

**🐍 Python:**
```python
import operator

result = sorted(users, key=lambda u: u.name)                  # sort_by 相当
result = sorted(users, key=operator.attrgetter("name"))       # &:name 風
result = sorted(users, key=lambda u: (u.last_name, u.first_name))
result = sorted(users, key=lambda u: u.created_at, reverse=True)  # 降順
```

### take/drop/first/last

```ruby
# 先頭から
top_5 = users.take(5)
top_5 = users.first(5)

# 末尾から
last_5 = users.last(5)

# スキップ
remaining = users.drop(5)

# 条件付き
users.take_while(&:active?)
users.drop_while(&:pending?)
```

**🐍 Python:**
```python
import itertools

top_5 = users[:5]        # take(5) / first(5) 相当（スライス）
last_5 = users[-5:]      # last(5) 相当
remaining = users[5:]    # drop(5) 相当
list(itertools.takewhile(lambda u: u.is_active, users))
list(itertools.dropwhile(lambda u: u.is_pending, users))
```

## 4. メソッドチェーン

### 基本的なチェーン

```ruby
result = users
  .select(&:active?)
  .reject(&:admin?)
  .sort_by(&:name)
  .map(&:email)
  .first(10)
```

**🐍 Python:**
```python
# リストにメソッドチェーンはない。内包表記 + sorted + スライスで組み立てる
filtered = (u for u in users if u.is_active and not u.is_admin)
emails = [u.email for u in sorted(filtered, key=lambda u: u.name)][:10]
```

### tap でデバッグ

```ruby
result = users
  .select(&:active?)
  .tap { |arr| puts "Active users: #{arr.size}" }
  .sort_by(&:name)
  .tap { |arr| puts "First: #{arr.first.name}" }
  .map(&:email)
```

> **🐍 Python:** `tap` に相当する組み込みはない。デバッグは中間変数に代入して `print()` するか、ロギングを挟む。

### then/yield_self

```ruby
# 値を変換してチェーン継続
result = fetch_data
  .then { |data| parse(data) }
  .then { |parsed| transform(parsed) }
  .then { |transformed| save(transformed) }

# 条件付き変換
value = input
  .then { |v| v.nil? ? default : v }
  .then { |v| process(v) }
```

> **🐍 Python:** `then`（パイプ）に相当する組み込みはない。`save(transform(parse(data)))` とネストするか、中間変数に順に代入する。

### チェーン可能なメソッド設計

```ruby
class QueryBuilder
  def initialize
    @conditions = []
    @order = nil
    @limit = nil
  end

  def where(condition)
    @conditions << condition
    self  # selfを返してチェーン可能に
  end

  def order(field)
    @order = field
    self
  end

  def limit(n)
    @limit = n
    self
  end

  def to_sql
    # SQLを生成
  end
end

query = QueryBuilder.new
  .where("status = 'active'")
  .where("age >= 18")
  .order("created_at DESC")
  .limit(10)
```

> **🐍 Python:** 各メソッドが `return self` する設計はPythonでも同様に書ける（`self` は明示）。呼び出しは `QueryBuilder().where(...).order(...).limit(10)` となる。

## 5. ブロックのイディオム

### ブロック vs do...end

```ruby
# {} は1行向け
items.each { |item| process(item) }
names = users.map { |u| u.name }

# do...end は複数行向け
items.each do |item|
  validate(item)
  process(item)
  save(item)
end

# 慣例: 戻り値を使う場合は {}
result = items.map { |item| transform(item) }

# 副作用が目的の場合は do...end
items.each do |item|
  puts item
end
```

> **🐍 Python:** ブロック構文はない。反復は `for item in items:`、変換は内包表記、コールバックは関数や `lambda` を引数で渡す。

### Symbol#to_proc

```ruby
# メソッド名をシンボルで
names = users.map(&:name)
# 同等: users.map { |u| u.name }

active = users.select(&:active?)
# 同等: users.select { |u| u.active? }

total = numbers.reduce(&:+)
# 同等: numbers.reduce { |a, b| a + b }
```

**🐍 Python:**
```python
import operator
from functools import reduce

names = [u.name for u in users]                              # &:name は内包表記が基本
names = list(map(operator.attrgetter("name"), users))        # attrgetter でも可
active = list(filter(operator.methodcaller("is_active"), users))  # &:active? 相当
total = reduce(operator.add, numbers)                        # &:+ 相当
```

### ブロックをメソッドに渡す

```ruby
def with_retry(max_attempts = 3)
  attempts = 0
  begin
    attempts += 1
    yield
  rescue => e
    retry if attempts < max_attempts
    raise
  end
end

with_retry(5) { api_call }
```

> **🐍 Python:** `yield` によるブロック渡しはない。関数を引数で受け取るか、リトライはデコレータ（例: `tenacity` の `@retry`）で実装するのが一般的。

### Proc/Lambda の活用

```ruby
# フィルタの再利用
active_filter = ->(u) { u.active? }
admin_filter = ->(u) { u.admin? }

active_users = users.select(&active_filter)
active_admins = users.select(&active_filter).select(&admin_filter)

# 設定として
VALIDATORS = {
  email: ->(v) { v.match?(/\A[\w+\-.]+@[a-z\d\-.]+\.[a-z]+\z/i) },
  phone: ->(v) { v.match?(/\A\d{10,11}\z/) }
}

def validate(field, value)
  VALIDATORS[field]&.call(value)
end
```

**🐍 Python:**
```python
import re

active_filter = lambda u: u.is_active
active_users = [u for u in users if active_filter(u)]

VALIDATORS = {
    "email": lambda v: re.fullmatch(r"[\w+\-.]+@[a-z\d\-.]+\.[a-z]+", v, re.I),
    "phone": lambda v: re.fullmatch(r"\d{10,11}", v),
}

def validate(field, value):
    validator = VALIDATORS.get(field)
    return validator(value) if validator else None
```

PEP8はラムダを名前に代入するより `def` を推奨するため、実務では通常の関数定義が好まれる。

## 6. 文字列操作

### 式展開

```ruby
# 基本
"Hello, #{name}!"

# 式を含む
"Total: #{items.sum}"
"Status: #{active? ? 'Active' : 'Inactive'}"

# メソッド呼び出し
"Name: #{user.name.upcase}"
```

**🐍 Python:**（f-string, 3.6+）
```python
f"Hello, {name}!"
f"Total: {sum(items)}"
f"Status: {'Active' if active else 'Inactive'}"
f"Name: {user.name.upper()}"
```

### ヒアドキュメント

```ruby
# 基本
sql = <<~SQL
  SELECT *
  FROM users
  WHERE active = true
SQL

# 式展開
message = <<~MSG
  Dear #{name},

  Your order ##{order_id} has been shipped.
MSG

# メソッドチェーン
query = <<~SQL.strip.gsub(/\s+/, ' ')
  SELECT *
  FROM users
  WHERE active = true
SQL
```

**🐍 Python:**
```python
import textwrap

sql = textwrap.dedent("""\
    SELECT *
    FROM users
    WHERE active = true
""")  # <<~ の字下げ除去は textwrap.dedent で行う

message = f"""\
Dear {name},

Your order #{order_id} has been shipped.
"""
```

三重クオート文字列はインデントをそのまま保持するため、`<<~` のような字下げ除去には `textwrap.dedent` を併用する。

### フォーマット

```ruby
# % 演算子
"Name: %s, Age: %d" % [name, age]

# sprintf / format
sprintf("%.2f", price)
format("%<name>s is %<age>d", name: "Alice", age: 25)
```

**🐍 Python:**
```python
"Name: %s, Age: %d" % (name, age)               # % 演算子（引数はタプル）
"%.2f" % price
"{name} is {age}".format(name="Alice", age=25)  # str.format
f"{price:.2f}"                                   # f-string（現代的で推奨）
```

### 正規表現

```ruby
# マッチング
email =~ /\A[\w+\-.]+@[a-z\d\-.]+\.[a-z]+\z/i
email.match?(/pattern/)  # 高速（Ruby 2.4+）

# 置換
text.gsub(/\s+/, ' ')
text.gsub(/\b\w/) { |match| match.upcase }

# キャプチャ
if match = text.match(/(\d+)-(\d+)-(\d+)/)
  year, month, day = match.captures
end
```

**🐍 Python:**
```python
import re

re.search(r"[\w+\-.]+@[a-z\d\-.]+\.[a-z]+", email, re.I)  # =~ 相当（部分一致）
bool(re.match(r"pattern", email))                         # 先頭からのマッチ
re.sub(r"\s+", " ", text)                                 # gsub 相当
re.sub(r"\b\w", lambda m: m.group().upper(), text)        # ブロック置換相当

m = re.search(r"(\d+)-(\d+)-(\d+)", text)
if m:
    year, month, day = m.groups()
```

単純な固定文字列の置換は `str.replace()` の方が高速で読みやすい。

## 7. オブジェクト生成

### ファクトリメソッド

```ruby
class User
  def self.guest
    new(name: "Guest", role: :guest)
  end

  def self.admin(name)
    new(name: name, role: :admin)
  end

  def self.from_hash(hash)
    new(**hash)
  end
end

guest = User.guest
admin = User.admin("Alice")
```

**🐍 Python:**
```python
class User:
    @classmethod
    def guest(cls):
        return cls(name="Guest", role="guest")

    @classmethod
    def from_dict(cls, data):
        return cls(**data)

guest = User.guest()
```

`self.new` に相当するのが `cls(...)`。`@classmethod` で第1引数にクラス自身を受け取る。

### ビルダーパターン

```ruby
class QueryBuilder
  def self.build
    builder = new
    yield(builder)
    builder.to_query
  end

  # ...
end

query = QueryBuilder.build do |b|
  b.select(:name, :email)
  b.from(:users)
  b.where(active: true)
end
```

> **🐍 Python:** ブロックを渡す `build do |b| ... end` の形はない。`b = QueryBuilder()` を作って設定してから `b.to_query()` を呼ぶか、`@dataclass` やキーワード引数でまとめて構築するのが一般的。

### Struct の活用

```ruby
# 簡易クラス
Point = Struct.new(:x, :y) do
  def distance_from_origin
    Math.sqrt(x**2 + y**2)
  end
end

point = Point.new(3, 4)
point.distance_from_origin  # => 5.0

# 値オブジェクト
Money = Struct.new(:amount, :currency, keyword_init: true)
price = Money.new(amount: 1000, currency: "JPY")
```

**🐍 Python:**
```python
from dataclasses import dataclass
import math

@dataclass
class Point:                          # Struct 相当
    x: float
    y: float

    def distance_from_origin(self):
        return math.sqrt(self.x ** 2 + self.y ** 2)

@dataclass(frozen=True)               # keyword_init 風 + イミュータブル
class Money:
    amount: int
    currency: str

price = Money(amount=1000, currency="JPY")
```

軽量な値の束なら `collections.namedtuple` や `typing.NamedTuple` も使える。

### freeze でイミュータブル

```ruby
# 定数の保護
DEFAULTS = {
  timeout: 30,
  retries: 3
}.freeze

# オブジェクトの凍結
class Config
  def initialize(options)
    @options = options.freeze
  end
end
```

**🐍 Python:**
```python
from types import MappingProxyType

DEFAULTS = MappingProxyType({"timeout": 30, "retries": 3})  # 読み取り専用の辞書ビュー
```

Pythonに任意オブジェクトを凍結する汎用の `freeze` はない。イミュータブルにするには `tuple` / `frozenset`、`@dataclass(frozen=True)`、`MappingProxyType` を使う。

## 8. メタプログラミング

### define_method

```ruby
class Model
  ATTRIBUTES = [:name, :email, :age]

  ATTRIBUTES.each do |attr|
    define_method(attr) { @attributes[attr] }
    define_method("#{attr}=") { |value| @attributes[attr] = value }
  end
end
```

**🐍 Python:**
```python
class Model:
    ATTRIBUTES = ["name", "email", "age"]

    def __init__(self):
        self._attributes = {}

    def __getattr__(self, name):          # 未定義属性の読み取りを動的に処理
        if name in type(self).ATTRIBUTES:
            return self._attributes.get(name)
        raise AttributeError(name)
```

メソッドを動的生成するより、`__getattr__` / `property` や `setattr` でアクセサを与えるのがPython流。

### method_missing

```ruby
class OpenStruct
  def initialize(hash = {})
    @data = hash
  end

  def method_missing(name, *args)
    if name.to_s.end_with?("=")
      @data[name.to_s.chop.to_sym] = args.first
    else
      @data[name]
    end
  end

  def respond_to_missing?(name, include_private = false)
    true
  end
end
```

**🐍 Python:**
```python
class OpenStruct:
    def __init__(self, data=None):
        object.__setattr__(self, "_data", data or {})

    def __getattr__(self, name):          # method_missing（読み取り）相当
        return self._data.get(name)

    def __setattr__(self, name, value):   # 代入（name=）相当
        self._data[name] = value
```

`method_missing` は `__getattr__`、`respond_to_missing?` は `__getattr__` が例外を投げるかどうかで表現する。

### クラスマクロ

```ruby
module Validatable
  def self.included(base)
    base.extend(ClassMethods)
  end

  module ClassMethods
    def validates(attribute, **options)
      validations[attribute] = options
    end

    def validations
      @validations ||= {}
    end
  end

  def valid?
    self.class.validations.all? do |attr, opts|
      value = send(attr)
      opts.all? { |type, arg| validate(type, value, arg) }
    end
  end
end

class User
  include Validatable
  validates :name, presence: true
  validates :email, format: /\A.+@.+\z/
end
```

> **🐍 Python:** `included` フックに直接相当するものはない。同様のDSLはクラスデコレータ、メタクラス、または `__init_subclass__` フックで実装する。宣言的なバリデーションは `pydantic` や `dataclasses` を使うのが一般的。

## 9. パフォーマンス最適化

### 文字列の凍結

```ruby
# 文字列リテラルを凍結（メモリ節約）
# frozen_string_literal: true

# または個別に
CONSTANT = "frozen".freeze
```

> **🐍 Python:** 文字列は元からイミュータブルなので `frozen_string_literal` に相当する概念は不要。同一オブジェクトへの正規化が必要なら `sys.intern()` を使う。

### 遅延評価

```ruby
# lazy で遅延評価
huge_array
  .lazy
  .select(&:valid?)
  .map(&:transform)
  .first(10)
  .to_a

# 無限シーケンス
(1..Float::INFINITY)
  .lazy
  .select { |n| n % 3 == 0 }
  .take(10)
  .to_a
```

**🐍 Python:**
```python
import itertools

# ジェネレータ式は lazy 相当（中間リストを作らない）
result = list(itertools.islice(
    (x.transform() for x in huge_array if x.is_valid()), 10
))

# 無限シーケンス
threes = (n for n in itertools.count(1) if n % 3 == 0)
list(itertools.islice(threes, 10))
```

### キャッシュ

```ruby
# インスタンスレベル
def expensive_calculation
  @result ||= perform_calculation
end

# クラスレベル
class Config
  def self.instance
    @instance ||= new
  end
end

# 条件付きキャッシュ
def data(force_reload: false)
  @data = nil if force_reload
  @data ||= load_data
end
```

**🐍 Python:**
```python
from functools import cached_property, lru_cache

class Config:
    @cached_property                 # ||= による遅延初期化 + キャッシュ相当
    def expensive_calculation(self):
        return perform_calculation()

@lru_cache(maxsize=None)             # 引数ごとに結果をキャッシュ
def load_config():
    return read_from_disk()
```

### 効率的なコレクション操作

```ruby
# 悪い例: 複数回のイテレーション
result = array.map { |x| x * 2 }.select { |x| x > 10 }.first(5)

# 良い例: 1回のイテレーション
result = []
array.each do |x|
  transformed = x * 2
  if transformed > 10
    result << transformed
    break if result.size >= 5
  end
end

# または lazy
result = array.lazy.map { |x| x * 2 }.select { |x| x > 10 }.first(5).to_a
```

**🐍 Python:**
```python
import itertools

# ジェネレータ式は中間リストを作らず、islice で先頭N件だけ評価する
doubled = (x * 2 for x in array)
result = list(itertools.islice((x for x in doubled if x > 10), 5))
```

### Set の活用

```ruby
require 'set'

# 悪い例: 配列での検索（O(n)）
valid_statuses = ["active", "pending", "approved"]
valid_statuses.include?(status)

# 良い例: Setでの検索（O(1)）
VALID_STATUSES = Set["active", "pending", "approved"]
VALID_STATUSES.include?(status)
```

**🐍 Python:**
```python
VALID_STATUSES = {"active", "pending", "approved"}  # set リテラル
status in VALID_STATUSES                             # O(1) の所属判定
```

## 10. アンチパターン

### 避けるべきパターン

```ruby
# 悪い例: 例外を握りつぶす
begin
  risky_operation
rescue
  # 何もしない
end

# 良い例: 最低限ログを残す
begin
  risky_operation
rescue => e
  logger.error("Error: #{e.message}")
  raise  # または適切に処理
end
```

**🐍 Python:**
```python
try:
    risky_operation()
except Exception as e:          # 裸の except: は非推奨
    logging.error("Error: %s", e)
    raise                        # または適切に処理
```

```ruby
# 悪い例: 過度なメタプログラミング
class User
  def method_missing(name, *args)
    # 何でも受け入れる
  end
end

# 良い例: 明示的なメソッド定義
class User
  attr_accessor :name, :email
end
```

```ruby
# 悪い例: グローバル変数
$config = load_config

# 良い例: シングルトンまたは依存性注入
class Config
  def self.instance
    @instance ||= new
  end
end
```

```ruby
# 悪い例: 深いネスト
def process(data)
  if data
    if data[:users]
      if data[:users].any?
        data[:users].each do |user|
          if user[:active]
            # ...
          end
        end
      end
    end
  end
end

# 良い例: 早期リターン
def process(data)
  return unless data
  return unless data[:users]&.any?

  data[:users].each do |user|
    next unless user[:active]
    # ...
  end
end
```

```ruby
# 悪い例: 神クラス
class User
  def save; end
  def send_email; end
  def generate_report; end
  def calculate_salary; end
  def update_inventory; end
end

# 良い例: 単一責任
class User
  def save; end
end

class UserMailer
  def send_email(user); end
end

class ReportGenerator
  def generate(user); end
end
```

```ruby
# 悪い例: マジックナンバー
if user.age >= 18
  # ...
end

# 良い例: 定数
LEGAL_AGE = 18

if user.age >= LEGAL_AGE
  # ...
end
```

```ruby
# 悪い例: N+1クエリ
users = User.all
users.each do |user|
  puts user.posts.count  # 各ユーザーでクエリ発行
end

# 良い例: Eager loading
users = User.includes(:posts).all
users.each do |user|
  puts user.posts.size
end
```

> **🐍 Python:** DjangoのORMでは `select_related`（1対1/多対1）や `prefetch_related`（1対多/多対多）でN+1を回避する。SQLAlchemyなら `joinedload` / `selectinload`。

## Ruby Style Guide のポイント

| カテゴリ | 推奨 |
|---------|------|
| インデント | スペース2つ |
| 行の長さ | 最大120文字 |
| メソッド | 10行以下を目安 |
| ブロック | 1行なら{}、複数行ならdo...end |
| 命名 | snake_case（変数/メソッド）、CamelCase（クラス） |
| 文字列 | 式展開はダブルクォート、それ以外はシングル |
| 配列 | %w[], %i[] を活用 |
| 比較 | == を使用、eql? は特殊な場合のみ |
| 真偽値 | and/or より && / \|\| |
