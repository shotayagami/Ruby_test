## 1. Rubyの哲学と特徴

### Rubyの設計思想

Rubyは「プログラマの幸福」を重視して設計されています。

```ruby
# 驚き最小の原則（Principle of Least Surprise）
# メソッド名から動作が予測できる

"hello".upcase     # => "HELLO" （予測通り）
[3, 1, 2].sort     # => [1, 2, 3] （予測通り）
5.times { |i| puts i }  # 5回繰り返す（予測通り）
```

### 他言語との大きな違い

```ruby
# 1. すべてがオブジェクト
42.class              # => Integer
42.even?              # => true
nil.class             # => NilClass
true.class            # => TrueClass

# 2. 括弧が省略可能
puts("Hello")         # OK
puts "Hello"          # OK（こちらが一般的）

# 3. 文末のセミコロン不要
x = 1
y = 2
z = x + y

# 4. returnが省略可能（最後の式が戻り値）
def add(a, b)
  a + b               # これが戻り値
end

# 5. 真偽値：false と nil のみが偽
if 0
  puts "0は真"        # これが実行される
end

if ""
  puts "空文字も真"   # これが実行される
end
```

**🐍 Python:**

```python
# 1. すべてがオブジェクトなのは Python も同じ（(42).bit_length() など）
# 2. メソッド呼び出しには括弧が必須（puts "x" のような省略は不可）
# 3. 文末セミコロンは任意（付けないのが普通）
# 4. return は省略できず、書かないと None を返す
def add(a, b):
    return a + b

# 5. 真偽値の扱いが大きく異なる：Python では 0・""・[]・{} も「偽」
if 0:
    print("実行されない")   # Ruby と逆で、ここは実行されない
```

Rubyで偽になるのは `false` と `nil` だけですが、Pythonでは `0`・空文字・空リストなども偽（falsy）として扱われます。この違いは条件分岐でよくハマるポイントです。

### Rubyのキーワード一覧

```ruby
# 制御構文
if, elsif, else, unless, case, when, then
while, until, for, do, end
begin, rescue, ensure, raise, retry
return, break, next, redo
yield

# 定義
def, undef, class, module, alias
defined?

# 論理・特殊値
and, or, not
true, false, nil
self, super
__FILE__, __LINE__, __ENCODING__

# その他
in, BEGIN, END
```

## 2. プログラムの構造

### 基本構造

```ruby
#!/usr/bin/env ruby
# encoding: utf-8

# 定数定義
VERSION = "1.0.0"

# クラス定義
class MyApp
  def initialize(name)
    @name = name
  end

  def run
    puts "Hello, #{@name}!"
  end
end

# メインプログラム
if __FILE__ == $0
  app = MyApp.new("World")
  app.run
end
```

**🐍 Python:**

```python
#!/usr/bin/env python3

# 定数（Python に本物の定数はなく、大文字は「変えない」という慣習）
VERSION = "1.0.0"

class MyApp:
    def __init__(self, name):
        self.name = name

    def run(self):
        print(f"Hello, {self.name}!")

# メインプログラム
if __name__ == "__main__":
    app = MyApp("World")
    app.run()
```

Rubyの `if __FILE__ == $0` に相当するのが Python の `if __name__ == "__main__":` です。インスタンス変数は Ruby の `@name` に対し、Python では `self.name` と明示します。

### `__FILE__` と `$0`

```ruby
# __FILE__: 現在のファイル名
# $0: 実行されたファイル名

# ライブラリとして読み込まれた場合は実行しない
if __FILE__ == $0
  # 直接実行された場合のみ実行
  main()
end
```

### requireとrequire_relative

```ruby
# 標準ライブラリの読み込み
require 'json'
require 'net/http'

# Gemの読み込み
require 'nokogiri'

# 相対パスでの読み込み
require_relative 'lib/my_class'
require_relative './helper'

# 違い
require 'my_lib'         # $LOAD_PATH から検索
require_relative 'lib'   # 現在のファイルからの相対パス
```

**🐍 Python:**

```python
# 標準ライブラリ / パッケージの読み込み
import json
import urllib.request

# 特定の名前だけ取り込む
from pathlib import Path

# 別名を付ける
import numpy as np
```

Python には `require` と `require_relative` の区別はなく、読み込みはすべて `import` で行います。読み込む単位はファイルの実行ではなく「モジュール」で、一度だけ読み込まれてキャッシュされる点は Ruby の `require` に近い動作です。

### loadとrequireの違い

```ruby
# require: 一度だけ読み込み（キャッシュされる）
require 'my_lib'
require 'my_lib'  # 2回目は何もしない

# load: 毎回読み込み
load 'my_lib.rb'
load 'my_lib.rb'  # 毎回読み込まれる

# 開発中の再読み込みにはloadが便利
```

## 3. コメント

### 単一行コメント

```ruby
# これはコメントです
x = 1  # 行末コメント

# TODO: あとで実装する
# FIXME: バグがある
# NOTE: 注意事項
# HACK: 一時的な対処
# OPTIMIZE: パフォーマンス改善が必要
```

> **🐍 Python:** 単一行コメントは `#` で共通。`x = 1  # 行末コメント` もそのまま通用します。

### 複数行コメント

```ruby
=begin
これは複数行コメントです。
ここに長い説明を書けます。
あまり使われませんが、存在は知っておきましょう。
=end

# 実際には複数の # を使うことが多い
#
# これも複数行のコメントとして使える
# こちらの方が一般的
#
```

**🐍 Python:**

```python
"""
Python に専用の複数行コメント構文はありません。
三重引用符の文字列（ドキュメンテーション文字列）を
コメント代わりに使う慣習があります。
"""

# 実際には各行に # を付けるのが確実
```

Rubyの `=begin`/`=end` に厳密に対応するものはなく、Pythonでは三重引用符 `"""..."""` の文字列リテラルで代用するのが一般的です。特に関数やクラスの先頭に置いた三重引用符は docstring として扱われます。

### ドキュメンテーションコメント（RDoc/YARD）

```ruby
# RDoc形式
#

#

#
#   user = User.new("太郎", 25)
#   user.greet

  def greet
    "こんにちは、#{@name}です"
  end
end
```

## 4. 変数と定数

### 変数の種類

```ruby
# ローカル変数（小文字またはアンダースコアで始まる）
name = "太郎"
user_age = 25
_private = "アンダースコア始まり"

# インスタンス変数（@で始まる）
@name = "太郎"
@user_count = 0

# クラス変数（@@で始まる）- 使用は推奨されない
@@total_count = 0

# グローバル変数（$で始まる）- 使用は非推奨
$global_config = {}

# 定数（大文字で始まる）
MAX_SIZE = 100
PI = 3.14159
MyClass = Class.new  # クラス名も定数
```

**🐍 Python:**

```python
# ローカル変数（記号のプレフィックスは不要）
name = "太郎"
user_age = 25

class User:
    class_attr = 0           # クラス変数（@@ 相当）

    def __init__(self):
        self.name = "太郎"    # インスタンス変数（@name 相当）

# グローバル変数（関数内で書き換えるには global 宣言が必要）
global_config = {}
def setup():
    global global_config
    global_config = {"debug": True}

# 定数（言語仕様上の定数はなく、大文字表記の慣習のみ）
MAX_SIZE = 100
```

Rubyは `@`・`@@`・`$` という記号で変数の種類を区別しますが、Pythonは記号を使わず、インスタンス変数は `self.x`、クラス変数はクラス直下の属性、グローバルは `global` 宣言で表します。定数はどちらも「大文字の慣習」で、再代入を言語が禁止するわけではありません。

### 変数のスコープ

```ruby
# ローカル変数のスコープ
x = 10  # トップレベル

def method_a
  y = 20      # メソッド内のローカル変数
  puts x      # エラー！xは見えない
end

if true
  z = 30      # if内でもスコープは同じ
end
puts z        # => 30（ブロック外でもアクセス可能）

[1, 2, 3].each do |n|
  item = n    # ブロック内のローカル変数
end
# puts item   # エラー！itemは見えない

# ブロック外の変数はブロック内で参照可能
counter = 0
[1, 2, 3].each do |n|
  counter += n  # 外の変数を参照・更新可能
end
puts counter    # => 6
```

### 定数の詳細

```ruby
# 定数の定義
MAX_RETRIES = 3
DEFAULT_OPTIONS = { timeout: 30, encoding: 'utf-8' }.freeze

# クラス/モジュール内の定数
class Config
  VERSION = "1.0.0"

  module Defaults
    TIMEOUT = 30
  end
end

Config::VERSION           # => "1.0.0"
Config::Defaults::TIMEOUT # => 30

# 定数は再代入可能（警告が出る）
MAX_RETRIES = 5  # warning: already initialized constant MAX_RETRIES

# freeze で変更を防ぐ
FROZEN_ARRAY = [1, 2, 3].freeze
# FROZEN_ARRAY << 4  # エラー！FrozenError
```

### 多重代入

```ruby
# 複数の変数に一度に代入
a, b, c = 1, 2, 3
puts a  # => 1
puts b  # => 2
puts c  # => 3

# 配列の展開
arr = [1, 2, 3]
x, y, z = arr
puts x  # => 1

# 要素数が合わない場合
a, b = 1, 2, 3     # a=1, b=2（3は捨てられる）
a, b, c = 1, 2     # a=1, b=2, c=nil

# スプラット演算子
first, *rest = [1, 2, 3, 4, 5]
puts first  # => 1
puts rest   # => [2, 3, 4, 5]

*head, last = [1, 2, 3, 4, 5]
puts head   # => [1, 2, 3, 4]
puts last   # => 5

# 変数の交換
a, b = b, a  # 一行でスワップ
```

**🐍 Python:**

```python
# 多重代入・変数交換は書き方までほぼ同じ
a, b, c = 1, 2, 3
a, b = b, a          # スワップも一行

# スプラット相当は * で受ける
first, *rest = [1, 2, 3, 4, 5]   # first=1, rest=[2, 3, 4, 5]
*head, last = [1, 2, 3, 4, 5]    # head=[1, 2, 3, 4], last=5
```

多重代入・スワップ・スプラット受け取りは Ruby とほぼ同じ感覚で書けます。ただし `a, b = 1, 2, 3` のように要素数が合わない場合、Ruby は余りを捨てますが Python は `ValueError` になります。

## 5. 文字列の詳細

### 文字列の作成

```ruby
# シングルクォート（エスケープシーケンス無効）
str1 = 'Hello\nWorld'   # \n はそのまま
str2 = 'It\'s OK'       # ' のエスケープのみ有効

# ダブルクォート（式展開・エスケープシーケンス有効）
name = "Ruby"
str3 = "Hello, #{name}!"     # => "Hello, Ruby!"
str4 = "Line1\nLine2"        # 改行が入る
str5 = "Tab\there"           # タブが入る

# %記法
str6 = %q(シングルクォート相当)   # エスケープなし
str7 = %Q(ダブルクォート相当)     # 式展開あり
str8 = %(これもダブルクォート)    # Qは省略可能

# 区切り文字は任意
str9 = %q|括弧以外も使える|
str10 = %q{波括弧}
str11 = %q!エクスクラメーション!
```

**🐍 Python:**

```python
# シングル/ダブルクォートに機能差はない（どちらも式展開しない）
str1 = 'Hello\nWorld'   # \n は改行として解釈される（Ruby のシングルとは違う）
str2 = "It's OK"

# 式展開したいときは f-string を使う
name = "Python"
str3 = f"Hello, {name}!"     # => "Hello, Python!"

# 生文字列（エスケープを無効化）は r プレフィックス
str4 = r'Hello\nWorld'       # \n はそのまま
```

Rubyはシングル/ダブルで式展開の有無が変わりますが、Pythonの `'...'` と `"..."` に機能差はありません。式展開したいときだけ `f"{name}"` のように f-string を使う、という切り分けになります。Ruby の `%q`/`%Q` に相当する記法はありません。

### ヒアドキュメント

```ruby
# 基本形
text = <<EOS
1行目
2行目
3行目
EOS

# インデントを保持
text = <<-EOS
  インデントも
  そのまま保持される
EOS

# インデントを削除（Ruby 2.3+、推奨）
text = <<~EOS
  先頭のインデントが
  自動的に削除される
  便利！
EOS

# 式展開あり/なし
name = "Ruby"
text1 = <<~EOS
  Hello, #{name}!
EOS

text2 = <<~'EOS'
  #{name}はそのまま
EOS

# メソッドチェーン
result = <<~SQL.strip.gsub(/\s+/, ' ')
  SELECT *
  FROM users
  WHERE active = true
SQL
```

**🐍 Python:**

```python
# 複数行文字列は三重引用符
text = """1行目
2行目
3行目"""

# f-string にすれば式展開もできる
name = "Python"
text2 = f"""
Hello, {name}!
"""
```

Rubyのヒアドキュメントに当たるのが三重引用符 `"""..."""` です。ただし `<<~` のような先頭インデントの自動除去はないため、必要なら `textwrap.dedent()` を使います。

### エスケープシーケンス

```ruby
# 主なエスケープシーケンス
"\n"    # 改行
"\t"    # タブ
"\r"    # キャリッジリターン
"\\"    # バックスラッシュ
"\""    # ダブルクォート
"\'"    # シングルクォート

# Unicode
"\u3042"           # => "あ"
"\u{3042 3044}"    # => "あい"（複数）

# 8進数・16進数
"\101"             # => "A"（8進数）
"\x41"             # => "A"（16進数）
```

### 文字列操作

```ruby
str = "Hello, World!"

# 長さ
str.length          # => 13
str.size            # => 13（同じ）
str.bytesize        # => 13（バイト数）

# アクセス
str[0]              # => "H"
str[-1]             # => "!"
str[0, 5]           # => "Hello"（位置, 長さ）
str[0..4]           # => "Hello"（範囲）
str[7..-1]          # => "World!"

# 検索
str.include?("World")     # => true
str.start_with?("Hello")  # => true
str.end_with?("!")        # => true
str.index("o")            # => 4（最初の位置）
str.rindex("o")           # => 8（最後の位置）

# 変換
str.upcase          # => "HELLO, WORLD!"
str.downcase        # => "hello, world!"
str.capitalize      # => "Hello, world!"
str.swapcase        # => "hELLO, wORLD!"
str.reverse         # => "!dlroW ,olleH"

# 空白処理
"  hello  ".strip   # => "hello"
"  hello  ".lstrip  # => "hello  "
"  hello  ".rstrip  # => "  hello"
"hello".center(11)  # => "   hello   "
"hello".ljust(10)   # => "hello     "
"hello".rjust(10)   # => "     hello"

# 置換
str.gsub("o", "0")        # => "Hell0, W0rld!"
str.gsub(/[aeiou]/, "*")  # => "H*ll*, W*rld!"
str.sub("o", "0")         # => "Hell0, World!"（最初の1つだけ）
str.delete("lo")          # => "He, Wrd!"
str.tr("a-z", "A-Z")      # => "HELLO, WORLD!"

# 分割・結合
"a,b,c".split(",")        # => ["a", "b", "c"]
"hello".chars             # => ["h", "e", "l", "l", "o"]
"hello".bytes             # => [104, 101, 108, 108, 111]
["a", "b", "c"].join("-") # => "a-b-c"
```

### 破壊的メソッド

```ruby
str = "hello"

# 非破壊的（元のオブジェクトは変わらない）
result = str.upcase
puts str      # => "hello"
puts result   # => "HELLO"

# 破壊的（! 付き、元のオブジェクトが変わる）
str.upcase!
puts str      # => "HELLO"

# 主な破壊的メソッド
str.downcase!
str.gsub!(/pattern/, "replacement")
str.strip!
str.chomp!    # 末尾の改行を削除
str.chop!     # 末尾の1文字を削除
```

## 6. 出力と入力

### 標準出力

```ruby
# puts: 改行あり
puts "Hello"
puts "World"
# Hello
# World

# print: 改行なし
print "Hello"
print "World"
# HelloWorld

# p: デバッグ用（inspect形式）
p "Hello\nWorld"    # => "Hello\nWorld"（改行が見える）
p [1, 2, 3]         # => [1, 2, 3]
p({ a: 1, b: 2 })   # => {:a=>1, :b=>2}

# pp: 整形出力（Pretty Print）
require 'pp'  # Ruby 2.5以降は不要
pp({ a: 1, b: { c: 2, d: 3 }, e: [4, 5, 6] })

# printf: フォーマット出力
printf("Name: %s, Age: %d\n", "太郎", 25)
printf("Pi: %.2f\n", 3.14159)

# sprintf / format: 文字列として取得
str = sprintf("Value: %05d", 42)  # => "Value: 00042"
str = format("%.2f%%", 3.14)      # => "3.14%"
str = "Name: %s" % "太郎"         # => "Name: 太郎"
```

**🐍 Python:**

```python
# print: 標準はスペース区切り・末尾に改行（puts に近い）
print("Hello")
print("Hello", end="")     # 改行なし（Ruby の print 相当）

# repr(): inspect 相当（Ruby の p に近い）
print(repr("Hello\nWorld"))   # => 'Hello\nWorld'

# pprint: 整形出力（Ruby の pp 相当）
from pprint import pprint
pprint({"a": 1, "b": {"c": 2, "d": 3}})

# フォーマットは f-string か format()
name, age = "太郎", 25
print(f"Name: {name}, Age: {age}")
print("Pi: {:.2f}".format(3.14159))
print("Value: %05d" % 42)     # % 記法も使えるが f-string が現代的
```

Rubyの `puts`/`print`/`p`/`pp` は、Pythonではおおむね `print()`（改行あり）/ `print(..., end="")`（改行なし）/ `print(repr(...))` / `pprint()` に対応します。`printf` に当たる専用関数はなく、f-string か `str.format` を使います。

### フォーマット指定子

```ruby
# %s: 文字列
# %d: 10進整数
# %f: 浮動小数点
# %x: 16進数（小文字）
# %X: 16進数（大文字）
# %o: 8進数
# %b: 2進数
# %%: % 自体

sprintf("%s", "hello")      # => "hello"
sprintf("%10s", "hello")    # => "     hello"（右寄せ）
sprintf("%-10s", "hello")   # => "hello     "（左寄せ）
sprintf("%d", 42)           # => "42"
sprintf("%5d", 42)          # => "   42"
sprintf("%05d", 42)         # => "00042"（ゼロ埋め）
sprintf("%.2f", 3.14159)    # => "3.14"
sprintf("%+d", 42)          # => "+42"（符号強制）
sprintf("%x", 255)          # => "ff"
sprintf("%X", 255)          # => "FF"
sprintf("%08b", 42)         # => "00101010"
```

### 標準入力

```ruby
# 1行読み込み
print "名前を入力: "
name = gets        # 改行を含む
name = gets.chomp  # 改行を除去

# 数値として読み込み
print "年齢を入力: "
age = gets.to_i

# 複数行読み込み
puts "テキストを入力（Ctrl+Dで終了）:"
text = $stdin.read

# 1文字読み込み
require 'io/console'
char = $stdin.getch

# パスワード入力（エコーなし）
require 'io/console'
print "Password: "
password = $stdin.noecho(&:gets).chomp
puts
```

**🐍 Python:**

```python
# 1行読み込み（改行は含まない。gets.chomp 相当）
name = input("名前を入力: ")

# 数値として読み込み
age = int(input("年齢を入力: "))

# 全入力を読み込み
import sys
text = sys.stdin.read()

# パスワード入力（エコーなし）
import getpass
password = getpass.getpass("Password: ")
```

Rubyの `gets` は末尾に改行を含み `chomp` で除去しますが、Pythonの `input()` は最初から改行を含みません。数値にしたいときは `gets.to_i` に対し Python は `int(input())` と明示的に変換します。

### ファイルディスクリプタ

```ruby
# 標準入力/出力/エラー
$stdin   # 標準入力
$stdout  # 標準出力
$stderr  # 標準エラー出力

# リダイレクト
$stderr.puts "エラーメッセージ"

# 一時的にリダイレクト
original_stdout = $stdout
$stdout = File.open("output.txt", "w")
puts "ファイルに出力"
$stdout.close
$stdout = original_stdout
```

## 7. 演算子

### 算術演算子

```ruby
# 基本演算
10 + 3      # => 13  加算
10 - 3      # => 7   減算
10 * 3      # => 30  乗算
10 / 3      # => 3   除算（整数同士は整数）
10.0 / 3    # => 3.333...（小数を含むと小数）
10 % 3      # => 1   剰余
10 ** 3     # => 1000 累乗

# divmod: 商と剰余を同時に取得
10.divmod(3)  # => [3, 1]

# 複合代入演算子
x = 10
x += 5    # x = x + 5
x -= 3    # x = x - 3
x *= 2    # x = x * 2
x /= 4    # x = x / 4
x %= 3    # x = x % 3
x **= 2   # x = x ** 2
```

**🐍 Python:**

```python
# 除算だけ大きく異なる：/ は常に小数、// が整数除算
10 / 3      # => 3.3333...（Ruby の 10 / 3 とは違い小数になる）
10 // 3     # => 3   整数除算（Ruby の整数同士の / に相当）
10 % 3      # => 1   剰余
10 ** 3     # => 1000 累乗（記号は同じ）
divmod(10, 3)  # => (3, 1)
```

Rubyは整数同士の `/` が整数除算（`10 / 3 => 3`）になりますが、Pythonの `/` は常に小数を返します。整数の商が欲しいときは `//` を使う、という違いに注意してください。

### 比較演算子

```ruby
# 基本比較
5 == 5      # => true   等しい
5 != 3      # => true   等しくない
5 > 3       # => true   より大きい
5 >= 5      # => true   以上
5 < 10      # => true   より小さい
5 <= 5      # => true   以下

# 宇宙船演算子（比較結果を数値で）
5 <=> 3     # => 1  （左が大きい）
3 <=> 5     # => -1 （右が大きい）
5 <=> 5     # => 0  （等しい）

# 型も含めた比較
5 == 5.0    # => true  （値が同じ）
5.eql?(5.0) # => false （型も同じか）
5.equal?(5) # => true  （同一オブジェクトか）

# オブジェクトIDの比較
a = "hello"
b = "hello"
c = a
a == b       # => true（値が同じ）
a.equal?(b)  # => false（別オブジェクト）
a.equal?(c)  # => true（同一オブジェクト）
```

### 論理演算子

```ruby
# and / &&
true && true    # => true
true && false   # => false
true and true   # => true（優先度が低い）

# or / ||
true || false   # => true
false || false  # => false
false or true   # => true（優先度が低い）

# not / !
!true           # => false
not true        # => false（優先度が低い）

# 短絡評価（ショートサーキット）
def check
  puts "called"
  true
end

false && check  # checkは呼ばれない
true || check   # checkは呼ばれない

# || を使ったデフォルト値
name = nil
name = name || "Guest"  # => "Guest"
name ||= "Guest"        # 同上（短縮形）

# && を使った安全なメソッド呼び出し
user = nil
# user && user.name  # nilなら評価しない
user&.name           # 同上（安全ナビゲーション演算子）
```

**🐍 Python:**

```python
# 論理演算子は記号ではなく英単語
True and True
True or False
not True

# || を使ったデフォルト値は or で書ける
name = None
name = name or "Guest"   # name ||= "Guest" に近い

# 安全ナビゲーション（&.）に相当する演算子はない
user = None
name = user.name if user else None
```

Pythonの論理演算子は `and`/`or`/`not` の英単語のみで、`&&`/`||`/`!` はありません（`&`/`|` はビット演算）。Rubyの安全ナビゲーション `&.` に当たる専用演算子はなく、`if` 式などで代用します。

### ビット演算子

```ruby
# AND
5 & 3       # => 1  (0101 & 0011 = 0001)

# OR
5 | 3       # => 7  (0101 | 0011 = 0111)

# XOR
5 ^ 3       # => 6  (0101 ^ 0011 = 0110)

# NOT
~5          # => -6 (ビット反転)

# シフト
8 >> 2      # => 2  (右シフト、1000 => 0010)
2 << 2      # => 8  (左シフト、0010 => 1000)

# 応用例：フラグ管理
READ    = 0b001
WRITE   = 0b010
EXECUTE = 0b100

permission = READ | WRITE  # => 0b011
permission & READ != 0     # => true（読み取り権限あり）
permission & EXECUTE != 0  # => false（実行権限なし）
```

### 範囲演算子

```ruby
# .. 終端を含む
(1..5).to_a    # => [1, 2, 3, 4, 5]

# ... 終端を含まない
(1...5).to_a   # => [1, 2, 3, 4]

# 文字列の範囲
("a".."e").to_a  # => ["a", "b", "c", "d", "e"]

# case文での使用
case score
when 90..100
  "A"
when 80...90
  "B"
else
  "C"
end

# 無限範囲（Ruby 2.6+）
(1..).take(5)     # => [1, 2, 3, 4, 5]
arr = [1, 2, 3, 4, 5]
arr[2..]          # => [3, 4, 5]
```

**🐍 Python:**

```python
# range は「終端を含まない」点が Ruby の ... に近い
list(range(1, 6))   # => [1, 2, 3, 4, 5]（1..5 相当）
list(range(1, 5))   # => [1, 2, 3, 4]  （1...5 相当）

# スライスも終端を含まない
[1, 2, 3, 4, 5][2:]   # => [3, 4, 5]
```

Rubyの `1..5`（終端含む）と `1...5`（終端含まない）に対し、Pythonの `range(start, stop)` やスライスは常に終端を含みません。`1..5` を作りたいときは `range(1, 6)` と +1 する点に注意します。

### 三項演算子

```ruby
# condition ? true_value : false_value
status = age >= 18 ? "成人" : "未成年"

# ネスト（読みにくいので非推奨）
grade = score >= 90 ? "A" : score >= 80 ? "B" : "C"

# 複雑な場合はif文を使う
grade = if score >= 90
          "A"
        elsif score >= 80
          "B"
        else
          "C"
        end
```

> **🐍 Python:** 三項演算子は語順が異なり `status = "成人" if age >= 18 else "未成年"` と書きます（`値 if 条件 else 値`）。

## 8. 式と文

### Rubyではすべてが式

```ruby
# if文も値を返す
result = if x > 0
           "positive"
         else
           "non-positive"
         end

# case文も値を返す
day_type = case day
           when "土", "日"
             "休日"
           else
             "平日"
           end

# メソッド定義も値を返す（シンボル）
result = def hello
           "Hello"
         end
puts result  # => :hello

# クラス定義も値を返す
result = class MyClass
           42
         end
puts result  # => 42
```

> **🐍 Python:** Python では `if`・`for`・関数/クラス定義などは「文」であり値を返しません（`x = if ...` は構文エラー）。値が欲しいときは三項式 `a if cond else b` や内包表記を使い、Ruby のように何でも代入できるわけではない点が大きな考え方の違いです。

### 後置条件

```ruby
# 後置if
puts "成人です" if age >= 18

# 後置unless
puts "未成年です" unless age >= 18

# 後置while（あまり使わない）
i = 0
i += 1 while i < 5

# 後置until
i = 0
i += 1 until i >= 5
```

### 式の連結

```ruby
# セミコロンで区切る
a = 1; b = 2; c = a + b

# 改行で区切る
a = 1
b = 2
c = a + b

# 行継続
result = 1 + 2 + 3 +
         4 + 5 + 6

# バックスラッシュで明示的に継続
long_string = "This is a very " \
              "long string"
```

## 9. 命名規則とコーディングスタイル

### 命名規則

```ruby
# ローカル変数・メソッド名: snake_case
user_name = "太郎"
def calculate_total
end

# 定数: SCREAMING_SNAKE_CASE
MAX_RETRY_COUNT = 3
DEFAULT_TIMEOUT = 30

# クラス・モジュール: PascalCase（CamelCase）
class UserAccount
end

module PaymentGateway
end

# シンボル: snake_case
:user_id
:created_at

# メソッドの接尾辞
def empty?      # 真偽値を返す
end

def save!       # 破壊的・例外を発生させる
end

def name=       # セッター
end
```

> **🐍 Python:** 命名規則はほぼ同じ（変数・メソッドは `snake_case`、クラスは `PascalCase`、定数は大文字）。ただし Ruby の `empty?` や `save!` のような `?`・`!` を含むメソッド名は Python では使えません（真偽を返す関数は `is_empty()` などと命名する慣習）。

### インデントと空白

```ruby
# インデント: スペース2つ
class User
  def initialize(name)
    @name = name
  end
end

# ハッシュ・配列
hash = {
  name: "太郎",
  age: 25,
  city: "東京"
}

array = [
  "item1",
  "item2",
  "item3"
]

# メソッド呼び出し
# 括弧なし（引数が単純な場合）
puts "Hello"
attr_reader :name

# 括弧あり（複雑な場合）
result = calculate(a, b, c)
User.create(name: "太郎", age: 25)
```

**🐍 Python:**

```python
# インデントは「見た目」ではなく構文そのもの（end は不要）
class User:
    def __init__(self, name):
        self.name = name        # インデントでブロックを表す

data = {
    "name": "太郎",
    "age": 25,
}
```

Rubyのインデントは可読性のための慣習で、ブロックの終わりは `end` で示します。一方 Python はインデント自体が構文で、ズレると `IndentationError` になります（`end` は不要）。この点が両言語の見た目上の最大の違いです。
